# Quick Start (2 phut)

## Buoc 1: Cai dependencies

```bash
cd Study
pip install -r requirements.txt
```

## Buoc 2: Chay Streamlit

```bash
streamlit run app.py
```

-> Browser mo tu dong `http://localhost:8501`

1. Sidebar: chon **Nhom noi dung** (`C/C++ Core (01-18)` hoac `Python & Debugging`)
