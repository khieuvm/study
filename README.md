# C/C++ Senior Interview Kit (Bilingual VI/EN)

Bo tai lieu nay giup on phong van C/C++ theo lo trinh tu co ban den nang cao, va da duoc toi uu de luyen phong van bang tieng Anh.

## Muc tieu

- Hoc ky thuat chuan senior (C/C++ core -> system design -> performance).
- Luyen cach tra loi song ngu, uu tien cau tra loi bang tieng Anh.
- Co the hoc tren laptop/dien thoai thong qua GitHub bat ky luc nao.

## Cau truc

- `01-c-core.md`: C core va low-level can ban (da theo format song ngu)
- `02-cpp-core.md`: C++ core, OOP, RAII, object model
- `03-modern-cpp.md`: C++11/14/17/20/23, templates, metaprogramming
- `04-stl-algorithm.md`: STL, complexity, iterator, idioms
- `05-concurrency.md`: thread, memory model, lock-free can ban
- `06-system-design-cpp.md`: thiet ke he thong bang C++ cho senior
- `07-debugging-performance.md`: profiling, debugging, optimization
- `08-behavioral-leadership.md`: behavioral + leadership cho senior
- `09-mock-interview-bank.md`: bo cau hoi tong hop co dap an ngan gon
- `study-plan-8-weeks.md`: ke hoach on 8 tuan
- `exercises/`: bai tap theo cap do + goi y dap an
- `BILINGUAL_QA_TEMPLATE.md`: template de chuyen cac file con lai sang song ngu

## Quy uoc song ngu

- Moi cau hoi van giu format: `### Q<n>. ...`
- Moi dap an bat dau bang `**A:**`
- Trong `**A:**` su dung 2 dong:
	- `EN: ...`
	- `VI: ...`
- Giu nguyen thuat ngu ky thuat bang tieng Anh (`ownership`, `undefined behavior`, `memory ordering`, ...).

## Cach su dung hang ngay

1. Hoc theo `study-plan-8-weeks.md`.
2. Moi ngay chon 10-15 cau, tu tra loi bang English truoc.
3. So sanh voi phan `EN` trong tai lieu, sau do doi chieu `VI` de dam bao hieu dung.
4. Ghi lai 3-5 follow-up interview questions cho chu de vua hoc.
5. Moi tuan lam 1 mock trong `09-mock-interview-bank.md`.

## Cach tra loi phong van (khuyen nghi)

- Bat dau bang one-line definition (EN).
- Neu co trade-off, tra loi theo khung: performance, safety, complexity, portability.
- Dua code ngn gon va no ro rang.
- Chot bang mot case thuc te da gap.
